    Trust this device

    Install this device's certificate once on each computer or phone that will open its secure address. It only vouches for this device's own name, nothing else. Before you install it, compare the fingerprint above with the one shown at the device or by your administrator.

    If this computer cannot reach the .local name or trust the certificate, Continue over HTTP for this browser session.

    If this computer cannot reach the .local name or trust the certificate, Continue on this address for this browser session. Your browser may continue to show a certificate warning.

    Maintenance

    Renew issues a new certificate for this device. Browsers and phones that already trust it keep working and nobody has to do anything. This happens automatically when it is close to expiry, if the product supports that.

    Reset creates a completely new identity. Every browser and phone has to install the new certificate again, and should remove the old one (its fingerprint is shown above). Only reset if you must, for example after renaming the computer.

    Your own certificate

    Use a certificate from your own certificate authority, if computers and phones here already trust it. Without one, the device keeps serving the certificate from its own authority.

    Recommended: create a signing request first. The device makes its own private key, which never leaves it, and your certificate authority signs the request. That works over plain HTTP too, and the key is an elliptic-curve key, which keeps connections fast. Uploading a certificate with its private key also works, over a secure connection only. If that key is an RSA key, every new secure connection to this device takes about twice as long to set up (about 1.5 seconds instead of 0.7), which slows a page load noticeably; an elliptic-curve key (P-256 or P-384) does not have that cost.

    Remove your certificate

    Deletes your certificate and any pending signing request. The device serves its own authority's certificate again, which computers and phones that already trust it accept. Renew and Reset always act on the device's own authority.
